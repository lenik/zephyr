== Name

some_puff1 - parse and format simple s-expressions (ANTLR4)

== Synopsis

*some_puff1* [_OPTION_]... [_FILE_]...

== Description

ANTLR4-based parser for simple s-expressions.
Default behavior is pretty-printed formatting; *--dump* prints an AST dump.

== Options

*-d, --dump*::
  Print an AST dump.

*-f, --format*::
  Pretty-print input (default).

*--indent-size* _NUM_::
  Indentation width (default 4).

*-C, --color* _MODE_::
  *auto*, *always*, or *never* (default *auto*).

*-h, --help*::
  Print usage and exit.

*--version*::
  Print version information and exit.
