== Name

zfr - багатомовні шаблони CLI-проєктів і допоміжні інструменти

== Synopsis

*zfr* *create* [*-l* _LANG_] [*-D* _DIST_] [*-1* _VER_] [*-a* _AUTHOR_]
              [*-e* _EMAIL_] _PROJECT_NAME_ [_PUFF_NAME_]...

*zfr* *rename* _PROJECT_NAME_ [_PUFF_NAME_]...

*zfr* *add* _PUFF_NAME_ [_PUFF_NAME_]...

*zfr* *remove* _PUFF_NAME_ [_PUFF_NAME_]...

*zfr* *about* [*-d*] [*-r*]

*zfr* *version* [*-g*] [*-c*] [*-r*]

*zfr* *lint* [*-l* _LEVEL_] [*-v*] [*-q*] [*--strict*] [*--color* _WHEN_]

*zfr* *shape* [*-b*] [*-v*] [*--threshold* _N_]

*zfr* *dist* [*-o* _DIR_] [*-b* _DIR_] [*-f* _FMT_] [*--rpm*]
            [*--allow-dirty*|*--no-allow-dirty*] [*--tests*]

*zfr* *ize* [*-l* _LANG_] [*-n*] [*-v*] [*--no-man*] [*--no-subst*]
           [*--color* _WHEN_]

*zfr* *release* [_OPTIONS_]

*zfr* *detect*

*zfr* *help*

*zfr-create*, *zfr-rename*, *zfr-add*, *zfr-remove*,
*zfr-about*, *zfr-version*, *zfr-lint*, *zfr-dist*, *zfr-ize*,
*zfr-shape* та *zfr-release* — тонкі обгортки над тими самими підкомандами.

== Description

*zfr* — інструмент командного рядка для колекції шаблонів *zephyr*.
Він постачає мовні шаблони для невеликих утиліт командного рядка та
засоби для їх створення й керування.

*Важливо:* створені проєкти мають і надалі викликати *zfr*
(наприклад, *zfr version* у *meson.build* і *rpm/Makefile*).
Рядок *zfr* *не* є магічним токеном create/rename і ніколи не
переписується в ім'я проєкту. Плейсхолдер шаблону, який *переписується*,
лишається *zephyr* (і *some_puff1* для прикладів puff).

Типовий робочий процес:

. Створити проєкт з мовного шаблону:
+
----
zfr create -l python myproj
----

. Увійти в проєкт і додати прикладні *puffs* (прикладні застосунки):
+
----
cd myproj
zfr add myapp another_app
----

. За потреби пізніше перейменувати проєкт або видалити puff за допомогою *rename* / *remove*.

Шаблони лежать у */usr/share/zephyr/<lang>/* після встановлення або в дереві
вихідного коду під час запуску неінстальованої обгортки builddir, наприклад *build/zfr*
(*ZFR_PKGDATADIR* перевизначає). Кожен шаблон може містити приклад puff з іменем
*some_puff1*; передайте імена puff у командному рядку *create*, щоб їх створити,
або пропустіть їх для порожнього проєкту.

У монорепозиторії *repodir* — корінь git- (або meta-) checkout, а *packagedir*
— дерево пакета з формою zephyr (наприклад *repodir/bash*).
Команди, що йдуть від поточного каталогу, спочатку визначають *packagedir*.

*i18n*::
  *zfr lint -l/--l10n-level* обирає потрібне покриття gettext і довідника.
  *L0* нічого не вимагає. *L1* (за замовчуванням) вимагає *de*, *es*, *fr*, *it*, *ja*,
  *ko*, *pl*, *ru*, *zh_CN*, *zh_TW*. *L2* вимагає їх плюс *bg*, *ca*,
  *cs*, *el*, *hu*, *id*, *nl*, *pt*, *sv*, *tr*. *L3* додає *da*, *et*, *fi*,
  *gl*, *hr*, *lt*, *ms*, *pt_BR*, *uk*, *vi*. Англійська (*en*) — вихідна мова
  *msgid* і не вказується в *po/LINGUAS*. Додаткові локалі понад рівень
  дозволені. Аргументи *lint* за замовчуванням запишіть у
  *.config/zfr/lint.options*. Сторінки довідника мають бути повними
  ручними перекладами в *docs/<locale>/* (не фрагментами po4a).

== Commands

*create*::
  Копіює *pkgdatadir/<lang>/* у новий каталог *./<project_name>/* (помилка,
  якщо каталог уже існує). Переписує *zephyr* → *_PROJECT_NAME_* і, коли
  задано імена puff, *some_puff1* → перший *_PUFF_NAME_* (решту через
  *add*). Без імен puff видаляє файли шаблонного puff, але зберігає
  токени *some_puff1*, щоб пізніше їх можна було створити через *add*.
  Записує новий *debian/changelog* (шаблонний changelog відкидається) з
  *--distribution* / *--init-version* / *--author* / *--email*, потім виконує
  *git init*, встановлює *core.hooksPath* у *.githooks* (копіює *pre-commit*,
  щоб *VERSION* лишався синхронізованим із *debian/changelog*), початковий
  коміт і анотований тег *vVER*.

*rename*::
  У поточному каталозі проєкту переписує *zephyr* → *_PROJECT_NAME_* і
  для кожного заданого імені переписує шаблонний puff *some_puff1* → це ім'я.
  *zfr* не переписує.

*add*::
  Визначає мову проєкту і копіює файли шаблонного puff у поточний
  проєкт, перейменовуючи *some_puff1* на кожен *_PUFF_NAME_*. Оновлює
  списки Meson (або еквівалентну проводку), коли це можливо.

*remove*::
  Видаляє файли та проводку Meson для кожного заданого імені puff із поточного
  проєкту.

*detect*::
  Виводить визначену мову для поточного каталогу
  (піднімається батьківськими каталогами до кореня проєкту).

*about*::
  Виводить інформацію про поточний проєкт. Піднімається від поточного
  каталогу до батьків, щоб знайти корінь проєкту (*meson.build* з
  *project()* або *debian/control*). Загальні поля (ім'я, версія, ліцензія,
  homepage, maintainer, summary, section, priority, distribution,
  architecture) розбираються з метаданих Debian або RPM і переносяться за
  шириною термінала. Також виводить кількість вихідних файлів/рядків і
  орієнтовний розмір корисного навантаження. Інтерактивні термінали
  використовують кольори CSR (console SGR), якщо не задано *NO_COLOR*.
  *-d* / *-r* — повний розібраний вигляд Debian або RPM
  (не дамп файлів пакування).

*version*::
  Виводить поточну версію проєкту (один рядок, для скриптів). За замовчуванням —
  *git describe*, коли доступні *git* і *.git*, інакше остання версія
  *debian/changelog*. Резерв — файл *VERSION*, потім *0.0.0*.
  Не-semver токен (наприклад, git hash) обгортається як *0.0.0-<token>*.

*lint*::
  Перевіряє поточний проєкт на відповідність стилю пакування та структури zephyr
  (піднімається від поточного каталогу до батьків, щоб знайти корінь проєкту).
  Повідомляє про відсутні файли, невідповідності ідентичності, помилки
  Meson/Debian/RPM, залишені токени *zephyr* / *some_puff1* у створених
  застосунках і запропоновані виправлення. Згадки *zfr* очікувані й не
  вважаються залишками. Для *.githooks/pre-commit* піднімається до *.git*,
  враховує *core.hooksPath* і перевіряє, що хук синхронізує *VERSION* з
  *debian/changelog*. Якщо є *po/* або *docs/\*.adoc*, попереджає, коли
  покриття не відповідає *--l10n-level* (див. *i18n* у Description;
  за замовчуванням *L1*, файл проєкту *.config/zfr/lint.options* може
  задати інший рівень).
  Зауважує наявність *src/commons.* (або застарілого *src/common_lib.*): ця
  назва лише приклад шаблону для спільних хелперів — у справжніх програмах
  перейменуйте на щось конкретне (*clib*/*cpplib* використовують *lib.c*/*lib.cpp*).
  Пропускає перевірки кількості рядків для тих прикладних модулів. Попереджає
  про вихідні файли довші за 1000 рядків; зауважує файли довші за 600 рядків
  (пропонує модуляризацію).
  Вивід призначений для людей і AI-кодерів: кожна знахідка має код,
  шлях і конкретне виправлення. Інтерактивні термінали використовують кольори CSR,
  якщо не задано *NO_COLOR*.

*shape*::
  Виводить оцінку *zephyr shape* 0–100 для поточного *packagedir* (наскільки
  повністю дерево відповідає стилю пакування zephyr). У монорепозиторії
  *packagedir* може відрізнятися від *repodir* (корінь git / meta); інструменти
  використовують shape, щоб надавати перевагу каталогу пакета над коренем репозиторію.
  *\-b* / *--bool* виводить *1*, якщо оцінка не нижча за поріг
  (за замовчуванням *50*), інакше *0*.

*dist*::
  Збирає вихідний архів поточного проєкту (піднімається від поточного
  каталогу до батьків, щоб знайти корінь проєкту). Коли цей каталог —
  корінь git-проєкту, виконує *meson dist* (після *meson setup*, за замовчуванням
  *--allow-dirty* і *--no-tests*). Вкладені мовні шаблони не мають
  власного *.git*, тож *meson dist* упакував би батьківський meta-repo;
  такі дерева отримують tar-архів каталогу лише цього проєкту. Виводить шлях
  до архіву в stdout. *dist* у *rpm/Makefile* і ninja-ціль Meson *srcdist*
  повторно використовують цю команду.

*release*::
  Розбирає ті самі опції, що й *gh-makerelease*(1), перезбирає argv і *exec*
  *gh-makerelease* з PATH. Ця команда сама не реалізує тегування,
  пакування чи завантаження на GitHub. Проєкт *zephyr* випускається з кореня
  git checkout (мовні шаблони плюс *zfr/*). Див. *Опції для release* нижче.

*ize*::
  Рефакторить поточний проєкт на місці, щоб він відповідав поточному стилю
  zephyr (піднімається від поточного каталогу до батьків). Копіює відсутній
  каркас *debian/* і *rpm/* з мовного шаблону (імена переписуються під
  цей проєкт), записує *VERSION* і *.githooks/pre-commit*, латає
  *meson.build* (*zfr version*, man-цілі *asciidoctor*, *run_target look*,
  встановлення bash-completion). Перетворює groff-сторінки *\*.1* у проєкті (не
  *debian/*) на *docs/\*.adoc* із правилами Meson і замінює захардкоджені
  версії changelog у *src/* на підстановки *\*.in* *@VERSION@* або
  *PROJECT_VERSION* через *config.h* для мов сімейства C.
  *\-n* / *--dry-run* виводить план без запису.
  Після цього запустіть *zfr lint*.

*help*::
  Показати довідку командного рядка.

== Options

Опції для *create*:

*-l, --lang* _LANG_::
  Мовний шаблон (за замовчуванням: *python*).
  Підтримувані значення включають *antlr*, *as*, *bash*, *bison*, *c*, *clib*, *cobol*, *cpp*, *cpplib*, *csharp*,
  *d*, *elixir*, *erlang*, *fortran*, *gcc*, *go*, *haskell*, *java*, *kotlin*, *lua*, *nim*, *ocaml*,
  *pascal*, *perl*, *python*, *ruby*, *rust*, *smalltalk*, *swift*, *typescript* і *zig*.
  Парсерні шаблони (*antlr*, *bison*) постачають CLI форматера/дампера з *--format* (за замовчуванням),
  *--dump*, *--indent-size* і *--color*.

*-D, --distribution* _DIST_::
  Дистрибутив у debian/changelog (за замовчуванням: *unstable*).

*-1, --init-version* _VER_::
  Початкова версія пакета і git-тег (за замовчуванням: *0.0.1*).

*-a, --author* _AUTHOR_::
  Ім'я автора changelog і git (за замовчуванням: *Lenik (谢继雷)*).

*-e, --email* _EMAIL_::
  Email автора changelog і git (за замовчуванням: *lenik@bodz.net*).

Опції для *about*:

*-d, --debian*::
  Показати розібрані поля пакування Debian (*debian/control*, остання
  строфа *debian/changelog*). Списки на кшталт *Build-Depends* переносяться за
  шириною термінала; довгий опис переформатовується абзацами.

*-r, --redhat*::
  Показати розібрані поля пакування RPM з *rpm/*.spec* (макроси на кшталт
  *%{version}* показуються за допомогою *zfr version -r*). Тіло *%description*
  переформатовується; scriptlets spec не виводяться.

*--color* _WHEN_::
  Підсвітка CSR: *auto* (за замовчуванням: TTY і немає *NO_COLOR*), *always* або
  *never*.

Опції для *version*:

*-g, --git*::
  Використати *git describe --tags --always --dirty* (за замовчуванням, коли
  доступні *git* і *.git*).

*-c, --changelog*::
  Використати останню версію *debian/changelog* (за замовчуванням, коли *git*
  або *.git* недоступні).

*-r, --rpm*::
  Вивести сумісну з RPM *Version* (дефіси замінюються на підкреслення).

Опції для *lint*:

*-v, --verbose*::
  Також виводити успішні перевірки.

*-q, --quiet*::
  Виводити лише помилки.

*--strict*::
  Вважати попередження помилками (код виходу 1).

*-l, --l10n-level* _LEVEL_::
  Потрібне покриття gettext і цілого документа довідника: *L0* (немає), *L1*
  (10 локалей, за замовчуванням), *L2* (20) або *L3* (30). *LEVEL* може бути *L2* або
  *2*. Значення за замовчуванням також беруться з *.config/zfr/lint.options*.

*--color* _WHEN_::
  Підсвітка CSR: *auto* (за замовчуванням: TTY і немає *NO_COLOR*), *always* або
  *never*.

Опції для *shape*:

*-b, --bool*::
  Вивести *1*, якщо оцінка shape не нижча за *--threshold*, інакше *0*.

*-v, --verbose*::
  Вивести *packagedir*, *repodir*, *role* і *threshold* у stderr.

*--threshold* _N_::
  Поріг для *--bool* (за замовчуванням: *50*).

Опції для *dist*:

*-o, --output* _DIR_::
  Записати архів у *_DIR_* (за замовчуванням: каталог Meson *meson-dist*
  або *rpmbuild/SOURCES* з *--rpm*).

*-b, --builddir* _DIR_::
  Каталог збірки Meson. За замовчуванням */build*, якщо цей builddir був
  налаштований для цього дерева вихідного коду, інакше *<project>/build*.

*-f, --format* _FMT_::
  Формат архіву: *xz* (за замовчуванням), *gz* або *zip*.

*--rpm*::
  Назвати архів *_NAME_*-*_VERSION_*.tar.xz і записати в
  *rpmbuild/SOURCES*, якщо не задано *-o*. Використовується *rpm/Makefile*.

*--allow-dirty*, *--no-allow-dirty*::
  Передати *--allow-dirty* у *meson dist* (за замовчуванням: дозволено).

*--tests*::
  Запускати тести під час *meson dist* (за замовчуванням *--no-tests*).

Опції для *release* (розбираються тут, передаються в *gh-makerelease*):

*-b, --build-binary*::
  Збірка лише бінарного пакета Debian (*-b*); без _.dsc_.
*-n, --no-pre-clean*::
  Повторно використати кеш збірки Debian.
*-u, --upload*::
  Повторно використати наявні артефакти версії, якщо вони є.
*--unsigned*::
  Зібрати непідписані пакети Debian (*-us -uc*).
*-p, --dput-host* _HOST_::
  Хост завантаження *dput*(1) для файлу _.changes_.
*-d, --docker*::
  Зібрати пакет Debian за допомогою *build4*(1) у Docker.
*-B, --base-image* _IMAGE_::
  Цільовий образ *build4* (за замовчуванням: *b4f-debian:trixie*).
*-s, --docker-server* _SERVER_::
  Запускати *build4* через SSH на *SERVER* (підрозуміває *-d*).
*-l, --local*::
  Лише збірка; без тега, push чи GitHub release.
*-f, --force*::
  Замінити наявний тег/release.
*-I, --no-install*::
  Пропустити *sudo dpkg -i*.
*-T, --no-tag*::
  Пропустити створення й push git release-тега.
*-U, --no-upload*::
  Пропустити *dput* файлу _.changes_.
*-R, --no-release*::
  Пропустити створення GitHub release.
*-P, --no-publish*::
  Пропустити публікацію на VSIX marketplace.
*-Y, --no-rpm*::
  Пропустити *make -C rpm rpm srpm*.
*-D, --no-deb*::
  Пропустити Debian *debuild*.
*-v, --verbose*::
  Докладне журналювання (можна повторювати).
*-q, --quiet*::
  Менше виводу (можна повторювати).

Опції для *ize*:

*-l, --lang* _LANG_::
  Мовний шаблон для копіювання каркасу (за замовчуванням: визначити).

*-n, --dry-run*::
  Вивести заплановані додавання/оновлення/перетворення без запису файлів.

*-v, --verbose*::
  Також виводити пропущені шляхи, які вже існують.

*--no-man*::
  Не перетворювати groff-джерела *\*.1* на *docs/\*.adoc*.

*--no-subst*::
  Не переписувати захардкоджені версії в *src/* на *@VERSION@* / *config.h*.

*--color* _WHEN_::
  Підсвітка CSR: *auto* (за замовчуванням: TTY і немає *NO_COLOR*), *always* або
  *never*.

== Environment

*ZFR_PKGDATADIR*::
  Перевизначити корінь шаблонів (зазвичай */usr/share/zephyr*).

*NO_COLOR*::
  Якщо задано, *zfr about*, *zfr lint* і *zfr ize* вимикають підсвітку CSR
  у режимі *--color auto*.

*PYTHONPATH*::
  Має включати каталог із пакетом *zfr_lib* під час запуску інструментів
  з нестандартної схеми встановлення.

== Tests

Дерево вихідного коду (не встановлений пакет) містить *tests/* із покриттям CLI
на Python *unittest*. *meson test* (каталог збірки */build*) знаходить
*tests/test_*.py*. Тести створюють тимчасові приклади проєктів і перевіряють кожну
підкоманду (*create*, *add*, *remove*, *rename*, *about*, *version*, *lint*,
*shape*, *dist*, *ize*, *release*, *detect*, *help*), обгортки *zfr-**,
оцінку впевненості мови, каталоги gettext і локалізовані довідники
*docs/<lang>/zfr.adoc* для кожної локалі.
Під час запуску без Meson задайте *ZFR_PKGDATADIR* на корінь checkout zephyr
(батько *zfr/*) і *PYTHONPATH* на *src/*.

== Files

*.config/zfr/lint.options*::
  Аргументи *zfr lint* за замовчуванням для цього проєкту (токени оболонки; коментарі *#*).
  Сам CLI zfr постачає *-l 2*.

*/usr/share/zephyr/<lang>/*::
  Встановлені мовні шаблони.

*/usr/bin/zfr*, */usr/bin/zfr-\**::
  CLI і тонкі обгортки.

*/usr/share/doc/zephyr/*::
  Документація пакета (LICENSE, README).

*/usr/share/man/<locale>/man1/zfr.1*::
  Локалізовані сторінки довідника, зібрані з *docs/<locale>/zfr.adoc*
  (повні переклади документів, не фрагменти gettext/po4a).

== Exit status

*0*::
  Успіх. Для *lint* у проєкті немає знахідок рівня помилки
  (попередження все одно виводяться, якщо не *--strict*).

*non-zero*::
  Сталася помилка (невідома мова, каталог призначення існує, збій
  визначення, відсутні файли puff, знахідки *lint* тощо).
