== Name

zfr - многоязычные шаблоны CLI-проектов и вспомогательные инструменты

== Synopsis

*zfr* *create* [*-l* _LANG_] [*-D* _DIST_] [*-1* _VER_] [*-a* _AUTHOR_]
              [*-e* _EMAIL_] _PROJECT_NAME_ [_PUFF_NAME_]...

*zfr* *rename* _PROJECT_NAME_ [_PUFF_NAME_]...

*zfr* *add* _PUFF_NAME_ [_PUFF_NAME_]...

*zfr* *remove* _PUFF_NAME_ [_PUFF_NAME_]...

*zfr* *about* [*-d*] [*-r*]

*zfr* *version* [*-g*] [*-c*] [*-r*]

*zfr* *lint* [*-v*] [*-q*] [*--strict*] [*--color* _WHEN_]

*zfr* *shape* [*-b*] [*-v*] [*--threshold* _N_]

*zfr* *dist* [*-o* _DIR_] [*-b* _DIR_] [*-f* _FMT_] [*--rpm*]
            [*--allow-dirty*|*--no-allow-dirty*] [*--tests*]

*zfr* *ize* [*-l* _LANG_] [*-n*] [*-v*] [*--no-man*] [*--no-subst*]
           [*--color* _WHEN_]

*zfr* *release* [_OPTIONS_]

*zfr* *detect*

*zfr* *help*

*zfr-create*, *zfr-rename*, *zfr-add*, *zfr-remove*,
*zfr-about*, *zfr-version*, *zfr-lint*, *zfr-dist*, *zfr-ize*,
*zfr-shape* и *zfr-release* — тонкие обёртки над теми же подкомандами.

== Description

*zfr* — инструмент командной строки для коллекции шаблонов *zephyr*.
Он предоставляет языковые шаблоны для небольших утилит командной строки и
средства для их создания и управления.

*Важно:* созданные проекты должны по-прежнему вызывать *zfr*
(например, *zfr version* в *meson.build* и *rpm/Makefile*).
Строка *zfr* *не* является магическим токеном create/rename и никогда
не переписывается в имя проекта. Плейсхолдер шаблона, который *переписывается*,
остаётся *zephyr* (и *some_puff1* для примеров puffs).

Типичный рабочий процесс:

. Создать проект из языкового шаблона:
+
----
zfr create -l python myproj
----

. Перейти в проект и добавить прикладные *puffs* (примерные приложения):
+
----
cd myproj
zfr add myapp another_app
----

. При необходимости позже переименовать проект или удалить puffs с помощью *rename* / *remove*.

Шаблоны расположены в */usr/share/zephyr/<lang>/* при установке или в дереве
исходников при запуске неустановленной обёртки builddir, например *build/zfr*
(переопределяется *ZFR_PKGDATADIR*). Каждый шаблон может включать пример puff
с именем *some_puff1*; передайте имена puffs в командной строке *create* для
их создания или опустите их для пустого проекта.

В монорепозитории *repodir* — корень git- (или meta-) checkout, а *packagedir*
— дерево пакета с формой zephyr (например, *repodir/bash*).
Команды, идущие от текущего каталога, сначала определяют *packagedir*.

*i18n*::
  Стиль Zephyr рекомендует покрытие gettext как минимум для:
  *ar*, *bn*, *de*, *es*, *fr*, *hi*, *id*, *it*, *ja*, *ko*, *pt*, *ru*,
  *sv*, *ta*, *te*, *th*, *tr*, *ur*, *vi*, *zh_CN*, *zh_TW*
  (псевдонимы *zh-cn* / *zh-tw*). Английский (*en*) — исходный язык *msgid*
  и не указывается в *po/LINGUAS*. Перечислите эти локали в *po/LINGUAS* и
  поставляйте соответствующие файлы *po/<locale>.po*.

== Commands

*create*::
  Копирует *pkgdatadir/<lang>/* в новый каталог *./<project_name>/* (ошибка,
  если каталог уже существует). Переписывает *zephyr* → *_PROJECT_NAME_* и,
  когда заданы имена puffs, *some_puff1* → первый *_PUFF_NAME_* (остальные
  через *add*). Без имён puffs удаляет файлы шаблонного puff, но сохраняет
  токены *some_puff1*, чтобы позже их можно было создать через *add*.
  Записывает новый *debian/changelog* (шаблонный changelog отбрасывается) с
  *--distribution* / *--init-version* / *--author* / *--email*, затем выполняет
  *git init*, устанавливает *core.hooksPath* в *.githooks* (копирует *pre-commit*,
  чтобы *VERSION* оставался синхронизирован с *debian/changelog*), начальный
  коммит и аннотированный тег *vVER*.

*rename*::
  В текущем каталоге проекта переписывает *zephyr* → *_PROJECT_NAME_* и
  для каждого заданного имени переписывает шаблонный puff *some_puff1* → это имя.
  *zfr* не переписывает.

*add*::
  Определяет язык проекта и копирует файлы шаблонного puff в текущий
  проект, переименовывая *some_puff1* в каждый *_PUFF_NAME_*. Обновляет
  списки Meson (или эквивалентную проводку), когда это возможно.

*remove*::
  Удаляет файлы и проводку Meson для каждого заданного имени puff из текущего
  проекта.

*detect*::
  Выводит определённый язык для текущего каталога
  (поднимается по родительским каталогам до корня проекта).

*about*::
  Выводит информацию о текущем проекте. Поднимается от текущего
  каталога к родителям для поиска корня проекта (*meson.build* с
  *project()* или *debian/control*). Общие поля (имя, версия, лицензия,
  homepage, maintainer, summary, section, priority, distribution,
  architecture) разбираются из метаданных Debian или RPM и переносятся по
  ширине терминала. Также выводит количество исходных файлов/строк и
  оценочный размер полезной нагрузки. Интерактивные терминалы используют
  цвета CSR (console SGR), если *NO_COLOR* не задан. *-d* / *-r* — полный
  разобранный вид Debian или RPM (не дамп файлов упаковки).

*version*::
  Выводит текущую версию проекта (одна строка, для скриптов). По умолчанию —
  *git describe*, когда доступны *git* и *.git*, иначе последняя версия
  *debian/changelog*. Запасной вариант — файл *VERSION*, затем *0.0.0*.
  Не-semver токен (например, git hash) оборачивается как *0.0.0-<token>*.

*lint*::
  Проверяет текущий проект на соответствие стилю упаковки и структуры zephyr
  (поднимается от текущего каталога к родителям для поиска корня проекта).
  Сообщает об отсутствующих файлах, несоответствиях идентичности, ошибках
  Meson/Debian/RPM, оставшихся токенах *zephyr* / *some_puff1* в созданных
  приложениях и предлагаемых исправлениях. Упоминания *zfr* ожидаемы и не
  считаются остатками. Для *.githooks/pre-commit* поднимается до *.git*,
  учитывает *core.hooksPath* и проверяет, что хук синхронизирует *VERSION* из
  *debian/changelog*. При наличии *po/* предупреждает, если *LINGUAS* не
  покрывает рекомендуемый набор локалей gettext (см. *i18n* в Description).
  Вывод предназначен для людей и AI-кодеров: каждая находка имеет код,
  путь и конкретное исправление. Интерактивные терминалы используют цвета CSR,
  если *NO_COLOR* не задан.

*shape*::
  Выводит оценку *zephyr shape* от 0 до 100 для текущего *packagedir* (насколько
  полностью дерево соответствует стилю упаковки zephyr). В монорепозитории
  *packagedir* может отличаться от *repodir* (корень git / meta); инструменты
  используют shape, чтобы предпочитать каталог пакета корню репозитория.
  *\-b* / *--bool* выводит *1*, если оценка не ниже порога
  (по умолчанию *50*), иначе *0*.

*dist*::
  Собирает исходный архив текущего проекта (поднимается от текущего
  каталога к родителям для поиска корня проекта). Когда этот каталог —
  корень git-проекта, выполняет *meson dist* (после *meson setup*, по умолчанию
  *--allow-dirty* и *--no-tests*). Вложенные языковые шаблоны не имеют
  собственного *.git*, поэтому *meson dist* упаковал бы родительский meta-repo;
  такие деревья получают tar-архив каталога только этого проекта. Выводит путь
  к архиву в stdout. *dist* в *rpm/Makefile* и ninja-цель Meson *srcdist*
  повторно используют эту команду.

*release*::
  Разбирает те же опции, что и *gh-makerelease*(1), пересобирает argv и *exec*
  *gh-makerelease* из PATH. Эта команда сама не реализует тегирование,
  упаковку или загрузку на GitHub. Проект *zephyr* выпускается из корня
  git checkout (языковые шаблоны плюс *zfr/*). См. *Опции для release* ниже.

*ize*::
  Рефакторит текущий проект на месте, чтобы он соответствовал текущему стилю
  zephyr (поднимается от текущего каталога к родителям). Копирует отсутствующий
  каркас *debian/* и *rpm/* из языкового шаблона (имена переписываются под
  этот проект), записывает *VERSION* и *.githooks/pre-commit*, патчит
  *meson.build* (*zfr version*, man-цели *asciidoctor*, *run_target look*,
  установка bash-completion). Преобразует groff-страницы *\*.1* в проекте (не
  *debian/*) в *docs/\*.adoc* с правилами Meson и заменяет захардкоженные
  версии changelog в *src/* на подстановки *\*.in* *@VERSION@* или
  *PROJECT_VERSION* через *config.h* для языков семейства C.
  *\-n* / *--dry-run* выводит план без записи.
  После этого запустите *zfr lint*.

*help*::
  Показать справку по командной строке.

== Options

Опции для *create*:

*-l, --lang* _LANG_::
  Языковой шаблон (по умолчанию: *python*).
  Поддерживаемые значения включают *bash*, *c*, *clib*, *cpp*, *cpplib*, *csharp*, *erlang*, *go*,
  *haskell*, *java*, *perl*, *python*, *ruby*, *rust*, *smalltalk*, *swift* и
  *typescript*.

*-D, --distribution* _DIST_::
  Дистрибутив в debian/changelog (по умолчанию: *unstable*).

*-1, --init-version* _VER_::
  Начальная версия пакета и git-тег (по умолчанию: *0.0.1*).

*-a, --author* _AUTHOR_::
  Имя автора changelog и git (по умолчанию: *Lenik (谢继雷)*).

*-e, --email* _EMAIL_::
  Email автора changelog и git (по умолчанию: *lenik@bodz.net*).

Опции для *about*:

*-d, --debian*::
  Показать разобранные поля упаковки Debian (*debian/control*, последняя
  запись *debian/changelog*). Списки вроде *Build-Depends* переносятся по
  ширине терминала; длинное описание переформатируется абзацами.

*-r, --redhat*::
  Показать разобранные поля упаковки RPM из *rpm/*.spec* (макросы вроде
  *%{version}* показываются с помощью *zfr version -r*). Тело *%description*
  переформатируется; scriptlets spec не выводятся.

*--color* _WHEN_::
  Подсветка CSR: *auto* (по умолчанию: TTY и нет *NO_COLOR*), *always* или
  *never*.

Опции для *version*:

*-g, --git*::
  Использовать *git describe --tags --always --dirty* (по умолчанию, когда
  доступны *git* и *.git*).

*-c, --changelog*::
  Использовать последнюю версию *debian/changelog* (по умолчанию, когда *git*
  или *.git* недоступны).

*-r, --rpm*::
  Вывести совместимую с RPM *Version* (дефисы заменяются на подчёркивания).

Опции для *lint*:

*-v, --verbose*::
  Также выводить пройденные проверки.

*-q, --quiet*::
  Выводить только ошибки.

*--strict*::
  Считать предупреждения ошибками (код выхода 1).

*--color* _WHEN_::
  Подсветка CSR: *auto* (по умолчанию: TTY и нет *NO_COLOR*), *always* или
  *never*.

Опции для *shape*:

*-b, --bool*::
  Вывести *1*, если оценка shape не ниже *--threshold*, иначе *0*.

*-v, --verbose*::
  Вывести *packagedir*, *repodir*, *role* и *threshold* в stderr.

*--threshold* _N_::
  Порог для *--bool* (по умолчанию: *50*).

Опции для *dist*:

*-o, --output* _DIR_::
  Записать архив в *_DIR_* (по умолчанию: каталог Meson *meson-dist*
  или *rpmbuild/SOURCES* с *--rpm*).

*-b, --builddir* _DIR_::
  Каталог сборки Meson. По умолчанию */build*, если этот builddir был
  настроен для данного дерева исходников, иначе *<project>/build*.

*-f, --format* _FMT_::
  Формат архива: *xz* (по умолчанию), *gz* или *zip*.

*--rpm*::
  Именовать архив *_NAME_*-*_VERSION_*.tar.xz и записать в
  *rpmbuild/SOURCES*, если не задан *-o*. Используется *rpm/Makefile*.

*--allow-dirty*, *--no-allow-dirty*::
  Передать *--allow-dirty* в *meson dist* (по умолчанию: разрешено).

*--tests*::
  Запускать тесты во время *meson dist* (по умолчанию *--no-tests*).

Опции для *release* (разбираются здесь, передаются в *gh-makerelease*):

*-b, --build-binary*::
  Сборка только бинарного Debian-пакета (*-b*); без _.dsc_.
*-n, --no-pre-clean*::
  Повторно использовать кэш сборки Debian.
*-u, --upload*::
  Повторно использовать существующие артефакты для версии, если они есть.
*--unsigned*::
  Собрать неподписанные Debian-пакеты (*-us -uc*).
*-p, --dput-host* _HOST_::
  Хост загрузки *dput*(1) для файла _.changes_.
*-d, --docker*::
  Собрать Debian-пакет с *build4*(1) в Docker.
*-B, --base-image* _IMAGE_::
  Целевой образ *build4* (по умолчанию: *b4f-debian:trixie*).
*-s, --docker-server* _SERVER_::
  Запускать *build4* по SSH на *SERVER* (подразумевает *-d*).
*-l, --local*::
  Только сборка; без тега, push или GitHub release.
*-f, --force*::
  Заменить существующий тег/release.
*-I, --no-install*::
  Пропустить *sudo dpkg -i*.
*-T, --no-tag*::
  Пропустить создание и push git release-тега.
*-U, --no-upload*::
  Пропустить *dput* файла _.changes_.
*-R, --no-release*::
  Пропустить создание GitHub release.
*-P, --no-publish*::
  Пропустить публикацию на VSIX marketplace.
*-Y, --no-rpm*::
  Пропустить *make -C rpm rpm srpm*.
*-D, --no-deb*::
  Пропустить Debian *debuild*.
*-v, --verbose*::
  Подробное логирование (можно повторять).
*-q, --quiet*::
  Меньше вывода (можно повторять).

Опции для *ize*:

*-l, --lang* _LANG_::
  Языковой шаблон для копирования каркаса (по умолчанию: определить).

*-n, --dry-run*::
  Вывести запланированные добавления/обновления/преобразования без записи файлов.

*-v, --verbose*::
  Также выводить пропущенные пути, которые уже существуют.

*--no-man*::
  Не преобразовывать groff-источники *\*.1* в *docs/\*.adoc*.

*--no-subst*::
  Не переписывать захардкоженные версии в *src/* в *@VERSION@* / *config.h*.

*--color* _WHEN_::
  Подсветка CSR: *auto* (по умолчанию: TTY и нет *NO_COLOR*), *always* или
  *never*.

== Environment

*ZFR_PKGDATADIR*::
  Переопределить корень шаблонов (обычно */usr/share/zephyr*).

*NO_COLOR*::
  Если задан, *zfr about*, *zfr lint* и *zfr ize* отключают подсветку CSR
  в режиме *--color auto*.

*PYTHONPATH*::
  Должен включать каталог с пакетом *zfr_lib* при запуске инструментов
  из нестандартной схемы установки.

== Tests

Дерево исходников (не установленный пакет) включает *tests/* с покрытием CLI
на Python *unittest*. *meson test* (каталог сборки */build*) находит
*tests/test_*.py*. Тесты создают временные примеры проектов и проверяют каждую
подкоманду (*create*, *add*, *remove*, *rename*, *about*, *version*, *lint*,
*shape*, *dist*, *ize*, *release*, *detect*, *help*), обёртки *zfr-**,
оценку уверенности языка, каталоги gettext и локализованные руководства
*docs/<lang>/zfr.adoc* для каждой локали.
При запуске без Meson задайте *ZFR_PKGDATADIR* на корень checkout zephyr
(родитель *zfr/*) и *PYTHONPATH* на *src/*.

== Files

*/usr/share/zephyr/<lang>/*::
  Установленные языковые шаблоны.

*/usr/bin/zfr*, */usr/bin/zfr-\**::
  CLI и тонкие обёртки.

*/usr/share/doc/zephyr/*::
  Документация пакета (LICENSE, README).

*/usr/share/man/<locale>/man1/zfr.1*::
  Локализованные страницы руководства, собранные из *docs/<locale>/zfr.adoc*
  (полные переводы документов, не фрагменты gettext/po4a).

== Exit status

*0*::
  Успех. Для *lint* в проекте нет находок уровня ошибки
  (предупреждения всё равно выводятся, если не *--strict*).

*non-zero*::
  Произошла ошибка (неизвестный язык, каталог назначения существует, сбой
  определения, отсутствуют файлы puff, находки *lint* и т. д.).
